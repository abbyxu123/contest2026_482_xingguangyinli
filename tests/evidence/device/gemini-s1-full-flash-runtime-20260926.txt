Display adaptation finding
--------------------------
The current panel remains on its initialization pattern while LVGL writes new
pixels to the active framebuffer. The built-in display-engine color-bar test
also leaves the panel image unchanged. Source and runtime inspection narrowed
the remaining integration item to the ILI9341 CPU/TCON transfer and landscape
rotation handoff:

- physical panel timing is 240 x 320;
- the Living Canvas/LVGL surface is 320 x 240;
- the optional G2D rotation path was enabled at compile time but its runtime
  rotation properties were absent, which previously produced a null rotation
  context during framebuffer update;
- the application framebuffer, touch input, display manager, full-image flash,
  and openvela boot path are independently operational.

This boundary is retained as an explicit adaptation item. It is not represented
as a completed on-panel Living Canvas demonstration.
